# CINEMA — React + TMDB API

## Запуск проекта

1. Распакуй ZIP и открой папку в VS Code.
2. В терминале выполни `npm install`.
3. В корне проекта создай файл `.env`.
4. Добавь свой TMDB Read Access Token:

```env
REACT_APP_TMDB_TOKEN=ТВОЙ_READ_ACCESS_TOKEN
```

5. Запусти проект командой `npm start`.

После создания или изменения `.env` перезапусти сервер разработки.

## Возможности проекта

- Главная страница в тёмном дизайне с золотистыми акцентами.
- Подборки: фильмы, которые сейчас в кино, популярные, с высоким рейтингом и скоро выйдут.
- Категории по жанрам: боевики, приключения, мультфильмы, комедии, криминал, документальные, драмы, семейные, фэнтези, история, ужасы, музыка, детективы, мелодрамы, фантастика, триллеры, военные и вестерны.
- Поиск фильмов по названию.
- Пагинация для просмотра следующих страниц каталога.
- Карточки с постерами, рейтингом и датой выхода.
- Страница подробной информации о фильме: описание, жанры, рейтинг, дата выхода, продолжительность и режиссёр.
- Актёрский состав: фотографии актёров, имена и персонажи, которых они сыграли.
- Просмотр трейлера на YouTube, если он доступен в TMDB.
- React Router, useState, useEffect, fetch.

## Используемые запросы TMDB

- `/movie/now_playing` — фильмы в кино.
- `/movie/popular` — популярные фильмы.
- `/movie/top_rated` — фильмы с высоким рейтингом.
- `/movie/upcoming` — ожидаемые премьеры.
- `/discover/movie` — фильмы по жанрам.
- `/search/movie` — поиск.
- `/movie/{movie_id}` — информация о фильме.
- `/movie/{movie_id}/credits` — актёрский состав и съёмочная группа.
- `/movie/{movie_id}/videos` — трейлеры.

## Важно

Не отправляй файл `.env` в GitHub или другим людям: в нём находится личный API-токен. Файл `.env` исключён из ZIP. Используй `.env.example` как образец.
